## 📦 Ключевые модули

### 1. **gameConfig.js** 🎮
Централизованное хранилище всех констант и конфигураций.

**Преимущества:**
- Одно место для изменения баланса игры
- Нет магических чисел в коде
- Легко тестировать различные конфигурации

**Содержит:**
```javascript
- GameConfig.CLICK (параметры кликов)
- GameConfig.PRESTIGE (престиж)
- GameConfig.EXPERIENCE (опыт)
- GameConfig.CASES (кейсы)
- GameConfig.TOWERS (башни)
- И многое другое...
```

### 2. **Player.js** 👤
Класс, инкапсулирующий все данные и логику игрока.

**Методы:**
```javascript
- constructor(data) // Инициализация
- addClicks(amount) // Добавить клики
- upgradeClickPower(cost) // Улучшить силу клика
- addExperience(amount) // Добавить опыт
- upgradeAbility(index) // Улучшить способность
- performPrestige() // Выполнить престиж
- addToInventory(itemName) // Добавить предмет
- removeFromInventory(index) // Удалить предмет
- getPlayerDamage() // Расчет урона
- getMaxDungeonHp() // Макс HP в подземелье
- toJSON() // Для сохранения
```

**Инкапсулирует:**
- Клики и улучшения
- Уровень и опыт
- Здоровье
- Способности
- Валюта и предметы
- Престиж и мультипликаторы

### 3. **DungeonSystem.js** 🏰
Управление боевой системой подземелий.

**Методы:**
```javascript
- initializeTower(towerIndex, playerMaxHp) // Войти в башню
- generateFloor(playerMaxHp) // Сгенерировать этаж
- dealPlayerDamage(damage) // Нанести урон
- nextFloor(playerMaxHp) // Перейти на следующий этаж
- getMonsterExpReward() // Получить опыт за монстра
- exit() // Выйти с сохранением
- giveUp() // Сдаться
```

**Отделяет логику боя от UI**

### 4. **StorageManager.js** 💾
Единая точка работы с localStorage.

**Методы:**
```javascript
- saveGame(player, dungeon) // Сохранить игру
- loadGame() // Загрузить игру
- resetGame() // Сбросить прогресс
- saveExpeditionTimer(...) // Сохранить таймер экспедиции
- loadExpeditionTimer(...) // Загрузить таймер
```

**Преимущества:**
- Централизованная обработка ошибок
- Миграция старых данных
- Простая замена хранилища (Firebase, Supabase и т.д.)

### 5. **UIManager.js** 🎨
Управление всем интерфейсом пользователя.

**Методы:**
```javascript
- cacheElements() // Кэширование DOM элементов
- initEventListeners() // Установка обработчиков
- updateProfile() // Обновить UI профиля
- updateInventory() // Обновить инвентарь
- handleClick() // Обработка клика
- handleUpgrade() // Обработка улучшения
- handleAbilityUpgrade(e) // Улучшение способности
- handleUseItem(e) // Использование предмета
```

**Отделяет UI от логики игры**

### 6. **itemUtils.js** 📦
Утилиты для работы с предметами.

```javascript
- getItemEffect(itemName) // Найти эффект предмета
- getItemEffectText(itemName) // Текстовое описание
- getHealAmount(itemName) // Количество хила
- getClickBonusAmount(itemName) // Бонус кликов
- getExpBonusAmount(itemName) // Бонус опыта
- isHealItem(itemName) // Проверка типа предмета
```

### 7. **NotificationSystem.js** 🔔
Система toast-уведомлений.

```javascript
- show(message, type, duration)
- success(message)
- error(message)
- info(message)
```

## 🚀 Как использовать новую архитектуру

### Инициализация
```javascript
// app.js автоматически инициализирует все при загрузке DOM
const app = new GameApp();
await app.initialize();
```

### Добавление нового предмета
1. Отредактировать `gameConfig.js` (добавить в CASES)
2. Логика отсчитается автоматически через `ItemUtils`

### Добавление новой башни
1. Добавить в `gameConfig.js` (TOWERS)
2. Новые монстры добавить в `DungeonSystem._getMonsterPool()`
3. Кнопки создадутся автоматически

### Добавление новой механики
1. Добавить метод в `Player.js`
2. Добавить обработчик в `UIManager.js`
3. Сохранение произойдет автоматически через `StorageManager`
