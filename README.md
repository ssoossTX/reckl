# 🎮 Кликер RPG - Модульная архитектура

Веб-игра в жанре RPG Кликер с системой боевых подземелий, предметов, опыта и престижа.

## ✨ Особенности

- 🖱️ **Система кликов** - улучшайте силу клика
- 🏰 **Подземелья** - сражайтесь с монстрами
- 🗺️ **Экспедиции** - выполняйте миссии
- 📦 **Кейсы** - открывайте сундуки с лутом
- 💎 **Валюта** - алмазы, ключи, клики
- 📊 **Прогрессия** - уровни, опыт, способности
- 💫 **Престиж** - перезагрузка с бонусами

## 🎯 Архитектура

### Принципы дизайна
- **Модульность** - каждый модуль отвечает за одно
- **Инкапсуляция** - данные защищены в классах
- **Разделение ответственности** - логика и UI отделены
- **DRY** - нет дублирования кода
- **Конфигурируемость** - все константы в одном месте

### Основные классы

**Player** - управляет всеми данными игрока
```javascript
const player = new Player();
player.addClicks(10);
player.addExperience(50);
player.upgradeClickPower(100);
```

**DungeonSystem** - управляет боевой системой
```javascript
const dungeon = new DungeonSystem();
dungeon.initializeTower(0);
dungeon.dealPlayerDamage(10);
dungeon.nextFloor();
```

**StorageManager** - управляет сохранениями
```javascript
StorageManager.saveGame(player, dungeon);
const { player, dungeon } = StorageManager.loadGame();
```

**UIManager** - управляет интерфейсом
```javascript
ui.updateProfile();
ui.handleClick();
ui.handleUpgrade();
```

## 🔧 Как использовать

### Изменить баланс игры
Отредактировать `src/constants/gameConfig.js`:
```javascript
GameConfig.CLICK.INITIAL_POWER = 2;  // Начальная сила клика
GameConfig.PRESTIGE.MULTIPLIER_GROWTH = 1.2;  // Рост престижа
```

### Добавить новый предмет
1. Добавить в `gameConfig.js` (раздел CASES)
2. Логика применится автоматически

### Добавить новую башню
1. Добавить в `gameConfig.js` (TOWERS.NAMES)
2. Добавить монстров в `DungeonSystem._getMonsterPool()`
3. Кнопка создастся автоматически

### Добавить новую механику
1. Добавить метод в `Player.js`
2. Добавить обработчик в `UIManager.js`
3. Вызвать в нужном месте

## 💾 Сохранение

Игра автоматически сохраняется:
- Каждые 5 секунд
- При выходе из вкладки
- После каждого действия

Сохранения хранятся в `localStorage` с ключом `rpgSave`.

## 🎮 Игровые системы

### Клик система
- Базовая сила клика улучшается за клики
- Стоимость улучшения возрастает
- Престиж дает мультипликатор к кликам

### Прогрессия
- Уровни повышаются за опыт
- Каждый уровень дает 3 поинта
- Поинты можно потратить на способности

### Способности
- **Сила** - +3 урона за точку
- **Ловкость** - +15 HP за точку
- **Интеллект** - +7% опыта за точку

### Подземелья
- 5 башен с разными монстрами
- Боссы на каждом 10м этаже
- Реликвии за победу над боссами
- Прогресс сохраняется

### Экспедиции
- 4 уровня сложности
- Требуемый уровень для каждой
- Таймер выполнения
- Шанс найти предмет
